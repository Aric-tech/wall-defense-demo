# 城墙防线｜浏览器试玩版

**[在线试玩](https://aric-tech.github.io/wall-defense-demo/)**

竖屏 Canvas 防守游戏个人练习项目。点击战场指定炮击落点，三座炮台根据落点与冷却状态发射；阻止敌人接近城墙。

## 玩法

- 三档难度、四类敌人、三座炮台。
- 支持双指点击、移动目标落点预判、暂停与结算。
- 首页、战斗及结算有独立音频；可在设置中调节和静音。

## 技术实现

- JavaScript 和 Canvas 2D 绘制竖屏战场。
- 开火请求队列、炮台独立冷却、目标位置预判与爆炸范围判定。
- 图片与音频资源分别加载，画面按屏幕尺寸适配。

## 本地运行

在仓库根目录运行 `python -m http.server 8000`，打开 `http://localhost:8000/`。

项目未附加开源许可证，素材请勿直接复用。
